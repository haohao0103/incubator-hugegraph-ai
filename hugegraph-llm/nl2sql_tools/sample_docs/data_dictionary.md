# 数仓数据字典（示例）

本文档是货拉拉电商数仓的业务术语字典，供语义层抽取术语定义使用。
每个术语给出业务定义、常用别名与涉及的物理字段。

## 交易域

**销售额**
指用户在平台完成支付、且未发生退款的订单金额合计，是衡量平台交易规模的核心指标。
别名：销售总额、交易额。
关联字段：payments 表的 pay_amount（支付金额）。

**支付总额**
用户实际支付成功的金额合计，以支付流水为准，不包含退款金额。
关联字段：payments.pay_amount。

**退款金额**
用户发起退款并经平台审核通过后实际退回的金额。
关联字段：refunds 表的 refund_amount。

**核销券数**
用户实际使用的优惠券数量（以核销记录为准）。
关联字段：coupons 表的 used_count（已核销数量）。

## 履约域

**履约时长**
订单从支付成功到用户签收所经历的小时数，反映履约效率。
别名：配送时长。
关联字段：logistics 表的 fulfillment_hours。

**发货时效**
订单支付后到物流发货的时间间隔。
关联字段：logistics 表的 ship_time。

## 门店域

**门店数**
统计周期内处于营业状态的门店数量。
关联字段：stores 表的 store_id（门店编号）。

**动销门店数**
统计周期内有实际销售产生的门店数量。
关联字段：stores 表（门店编号），需与销售明细关联计算。
