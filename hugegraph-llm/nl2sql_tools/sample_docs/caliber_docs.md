# 指标口径说明文档（示例）

本文档定义数仓核心指标的统计口径，供语义层抽取口径约束。
口径是同一指标在不同维度下的计算约束，生成 SQL 时必须遵守。

## GMV口径（成交总额）

- 适用指标：成交额
- 约束维度：status（订单状态）
- 口径描述：成交额仅统计订单状态为 paid（已支付）的订单金额之和；退款、取消的订单一律不计入。
- 适用字段：orders 表 gmv 字段 / 汇总表 ads_daily_sales 的 gmv。

## 销售额口径

- 适用指标：销售额
- 约束维度：status（支付状态）
- 口径描述：销售额 = 用户实际支付成功的订单金额合计，即 payments.pay_amount 之和；不含退款金额、不含未支付订单。
- 适用字段：payments 表的 pay_amount。

## 实付口径

- 适用指标：支付总额
- 约束维度：status
- 口径描述：支付总额 = 用户实际支付成功的金额合计（pay_amount），不含退款金额。
- 适用字段：payments 表的 pay_amount。

## 客单价口径

- 适用指标：客单价
- 约束维度：grain（粒度）
- 口径描述：客单价 = 成交总额 / 订单数，分母必须为订单数（order_cnt），不得用用户数替代。
- 适用字段：ads_daily_sales 表的 avg_order_value、order_cnt。

## 履约时效口径

- 适用指标：履约时长
- 约束维度：time（统计区间）
- 口径描述：履约时长 = 订单支付成功时刻到签收时刻的小时差，仅统计状态为已签收（received）的订单；未签收订单不纳入计算。
- 适用字段：logistics 表的 fulfillment_hours。

## 发货时效口径

- 适用指标：发货时效
- 约束维度：status
- 口径描述：发货时效 = 订单支付成功时刻到物流发货时刻的小时差，仅统计已发货订单。
- 适用字段：logistics 表的 ship_time。
