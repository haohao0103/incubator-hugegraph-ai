# 业务指标口径说明（平台口径文档 · 模拟飞书 wiki）

> 本文档为平台口径权威来源。各业务线指标定义与公式以本文档为准，
> 指标口径如有调整需在本文档同步更新。

## 交易域指标

- 订单总额（order_total）：订单表订单金额求和。公式：SUM(order.amount)。来源表：order；来源字段：order.amount。
- 支付总额（payment_total）：支付表支付金额求和。公式：SUM(payment.amount)。来源表：payment；来源字段：payment.amount。
- 订单数（order_count）：订单总数。公式：COUNT(order.order_id)。来源表：order；来源字段：order.order_id。
- 客单价（avg_order_value）：平均每单成交金额 = 订单总额 / 订单数。公式：SUM(order.amount) / COUNT(DISTINCT order.order_id)。来源表：order；来源字段：order.amount, order.order_id。依赖指标：order_total。

## 司机域指标

- 司机订单数（driver_order_cnt）：每位司机完成的订单数量。公式：COUNT(DISTINCT order.order_id)，按 driver_id 分组。来源表：order, driver；来源字段：order.driver_id, order.order_id。依赖指标：order_count。

## 附注

- 所有金额类指标默认单位：元，保留两位小数。
- 所有指标默认按自然日 T+1 产出。
